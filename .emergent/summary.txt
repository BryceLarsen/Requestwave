**Key Technical Concepts**
- State-Driven Conditional UI (React state in a single component)
- 3-tier Data Merging: Master Musician -> Profile -> Event (Note: Social links strictly do *not* merge from master to profile anymore).
- Dynamic Origin Routing: Audience URLs are generated at runtime using `window.location.origin` rather than hardcoded environment variables.
- Post-build HTML emission: `package.json` contains a script to copy `build/index.html` to `build/rw-ops.html` so direct SPA routing works on static file servers.
