Upcoming Tasks (P0)

Implement Analytics Event System

File: /app/backend/server.py

Core Requirements
	•	Add a new append-only MongoDB collection: analytics_events
	•	Add AnalyticsEvent Pydantic model
	•	Add centralized helper: emit_analytics_event(...)
	•	Guard all analytics writes behind:
ANALYTICS_EVENTS_ENABLED = true  # default true in preview
	•	If disabled:
	•	Do nothing
	•	Never throw
	•	Never log errors

Critical Guardrails (Do NOT violate)
	•	Append-only: events are never updated or deleted.
	•	Event writes must be non-blocking:
	•	Await insert with short timeout (≈150–250ms).
	•	Swallow all exceptions.
	•	Log errors only.
	•	Event timestamp stored as UTC datetime (not ISO string).
	•	Normalized requester email (lower().strip()) stored only for:
	•	audience.request_submitted
	•	audience.suggestion_submitted
	•	Do NOT emit batch events in phase 1.
	•	Do NOT modify existing analytics UI or calculations.
